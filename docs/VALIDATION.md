# 验证方法与边界

完整验证入口为 `python3 scripts/validate.py`，详细环境见[开发文档](DEVELOPMENT.md)。验证顺序为公开资料/许可证/版本门禁、宿主故障注入、Swift 逻辑与原生窗口测试、双架构 Release 编译、导出源码在独立路径和缓存中的重新编译。具体次数与结果必须由实际命令输出记录；新增 CI 配置不等于远端已经运行通过。

## 0.9.5 build 905 本地交互审计

三个测试专项分别覆盖搜索、下载和设置/弹窗，另检查共享控件。新增回归覆盖长列表的追加/删除/筛选、进度变化、旧按钮失效、详情保持、横向表头同步、禁用恢复、下拉菜单、数值输入、账号忙碌/失败/取消、环境检查重开和长保存路径。所有账号、下载执行器及存储均为合成或隔离数据。

修复前分别记录下载列表位置跳动、旧动作、详情关闭、表头错位、标签边界及长路径挤出按钮的失败；修复后执行专项和完整门禁。实际鼠标复核使用独立应用标识及临时目录，复制使用独立剪贴板；不操作用户正在运行的应用、真实账号或下载任务。原生窗口命中测试和真实鼠标检查分别记录，不把合成测试解释为真实平台成功率或旧系统实测。

## 0.9.4 下载管理按钮

新增窗口级命中与动作回归：1/4/20行任务中按钮的不同位置、未选中首行、进度刷新、失败详情、重试及取消、换源、文件缺失提示、长列表滚动后筛选为空/单行和窗口缩放。搜索与下载共享表头滚动留白实现，防止浮动表头的内部命中区域吞掉按钮点击。

另以独立测试应用标识、独立临时存储和合成后台做实际鼠标坐标点击：修复前首行「显示文件」无响应而下一行「取消」可用；修复后首行成功在Finder定位自有测试文件，取消、详情、换源、筛选后首行重试及再次取消均反映了相应状态变化。此隔离测试未读取真实账号或用户下载任务，不代表对真实平台下载成功率作保证。测试窗口与打包源码的表格、控件和模型实现一致，测试执行器及样本数据不进入分发包。

2026-11-07统一验证：227项Swift检查零失败，其中2项跨卷/ExFAT条件不适用而跳过；40项宿主测试和公开源码重定位后独立编译通过。双架构Release、原生UI/WebKit、本地五格式媒体及安装副本的结果由本版安装包旁报告记录。

## 测试范围

Swift 回归覆盖真实 AppKit 表格与控件、全选、输入与菜单、任务 FIFO/取消/重试/晚到回调、账号切换与凭据引用、默认匿名访问、匿名/登录证明分离、六来源解析、HTTPS/CDN 与 HTTP 长度边界。合成音频覆盖 128 KiB 试读、五格式导出、截断与坏帧拒绝、整段解码、同名和符号链接保护、歌词异常与临时清理。

下载表格另检查固定行高、长失败原因的完整说明、进度更新保持选择、禁用状态、行复用操作身份和移除任务关闭详情。实际原生窗口回归覆盖滚动后筛选/清理至 1–4 项，验证文字实际绘制而非仅检查模型数量。

宿主测试覆盖源码白名单、自身与第三方许可、版本/资源一致性、旧运行时拒绝、CPU/minOS 解析、符号 UUID、拒绝覆盖、排他发布回滚、进程锁争用、SIGTERM 子进程/暂存清理，以及 attach/detach 故障保护。使用隔离 pytest 环境，不依赖未声明的全局模块。

## 安装包与人工复核

打包脚本对每架构分别验证签名、单一 CPU、Mach-O/Info.plist 最低系统、项目与第三方许可、源码 SHA、无 Python/旧引擎、Finder 安装背景和 Applications 链接。只读挂载并复制最终 App 后，再执行本地 HTTP、原生 UI、WebKit 合成连接及五格式媒体 smoke。产物旁 verification.json 和 SHA-256 绑定对应包。

人工截图需来自最终 App 的隔离合成数据，检查 1080×740 和常用窗口、浅深外观、长标题、下载失败与进度，以及环境安装说明。保留匹配 dSYM 便于诊断。Apple Silicon 主机上的 Intel/Rosetta 检查、原生 Intel 实机及 macOS 12.7.6 验收分别记录；编译的 deployment target 不构成旧系统实测。

当前构建/验证不发布、不覆盖已有安装、不读取用户真实账号。未配置 Developer ID/公证，不宣称可以无提示分发，也不把软件 MIT 许可当作音乐内容授权。
