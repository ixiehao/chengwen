# 六源适配与匿名完整音频验证

0.9.0 保持纯 Swift。六个音源使用相同的验收标准：搜索成功、少量音频可试读、实际匿名完整下载、使用账号后的完整下载分别记录。

## 代码与参考来源

四个新增来源以 [Listen1 的 MIT 固定版本](https://github.com/listen1/listen1_chrome_extension/tree/3f24efa045125875a609dcb0f3f3f0be4edb8b37)作为公开接口参考，并用0.7.0引擎验证时的正常官方响应核对请求和字段。许可证及版权声明随应用分发，不引入浏览器扩展、JS/Node/Python运行时或第三方解析服务器。

- `NativeAdditionalSources`：身份和文本规范化、受控HTTPS媒体域名、匿名网络传输及错误分类。
- `NativeQQSource`：QQ官方CGI搜索和匿名VKey；由平台返回默认普通音质，可能为M4A，之后可用现有管线保存MP3等格式。
- `NativeKugouSource`：酷狗官方搜索及移动网页播放信息；付费条目不会冒充免费资源。
- `NativeMiguSource`：咪咕PC裸数组搜索、独立copyrightId/contentId、PQ匿名地址；不发送假UID。
- `NativeQianqianSource`：千千音乐公开网页请求签名与单曲地址；`audio04.dmhmusic.com`等媒体主机由官方接口直接下发，不是第三方解析站。
- 原网易云和酷我继续使用系统网络与现有Swift实现，也按匿名整首标准重新实测。

参考的许可证只覆盖代码，不赋予音乐内容授权。未将附加禁止打包/商业限制、无许可证或不符合本项目分发要求的实现移植进应用。正常公共应用请求签名不包含用户账号或登录票据，不做平台音频解密、代持账号、权限或验证绕过。

## 默认免登录

新旧六源默认均不使用账号，即使本机保存过会话也不自动附带。若显式启用「下载时使用已连接账号」，只有之后加入的网易云/酷我任务可使用对应会话；其他四源仍完全匿名。切换访问方式清除已有试读缓存。任务结果分别记录匿名和账号访问，不把账号成功计为匿名成功。

## 三个阶段

| 阶段 | 可以说明什么 | 不说明什么 |
| --- | --- | --- |
| 搜索有结果 | 平台提供了歌曲元数据 | 不代表提供匿名音频权限 |
| 蓝色「可试读」 | 最多128KiB音频读取成功 | 不代表整首已下载或已校验 |
| 绿色「整首已验证」 | 文件实际下载，经过FFprobe、完整FFmpeg解码与时长检查 | 不保证其他歌曲或未来再次下载也成功 |

来源状态只统计当前结果：搜索状态、匿名整首已验证、登录整首已验证和仅可试读分别显示。整首证明只接受下载管线的明确结果，试读返回值、完成进度包、缺失访问方式、旧搜索/账号/退出后的迟到回调都不能伪造匿名证明。

所有来源都拒绝明确的试听、付费/权限拒绝、额外验证、矛盾失败码、错误资源身份和不支持的受保护音频。重试仍失败，选择同平台允许匿名访问的其他版本或换源；不通过第三方站点补链。

## 匿名整首实测

2026-11-03，0.8.0严格解码与HTTP边界修复后，六个来源各一个匿名整首样本复核通过。未登录、未发Cookie和账号引用，媒体只写临时目录，校验后删除。具体时长、字节数和核心文件SHA见[0.8.0脱敏结果](backend-validation/native-080-anonymous.json)，早期结果见[0.7.0历史记录](backend-validation/native-070-anonymous.json)。这是有限样本记录，不是全曲库成功率或VIP曲目可下载保证。

显式CLI复核入口（隔离目录，不打开UI、加载偏好或访问账号）：

```sh
swift build --scratch-path .build-native
# 用 swift build --scratch-path .build-native --show-bin-path 查找实际目录
/path/to/澄闻 --source-check --source migu --keyword 小星星 --download
```

单次只解析至多两个候选，优先免费元数据，并执行完整媒体校验。默认只试读时，JSON中明确标记 `validation_scope=bounded_preview`，不能当作完整下载证明。
