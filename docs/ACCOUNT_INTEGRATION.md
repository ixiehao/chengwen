# 0.9.0 原生账号连接

账号页只提供网易云与酷我。系统WKWebView使用独立非持久会话承载官方页面，扫码及安全挑战由平台处理；用户完成后显式连接。无密码收集、浏览器资料提取或Python进程。

会话按数据目录、平台和32位版本隔离保存在macOS通用密码钥匙串服务local.vmdown.accounts.v2。候选与公开引用分开发布，取消、写入失败和迟到回调不覆盖旧有效账号。前端只提交候选引用，原生服务验证域名、有效期、身份与平台业务结果；设置和历史不保存Cookie/SID。

下载逐曲校验平台授权、歌曲匹配、试听/保护格式；账号过期、风险挑战和权益不足明确区分。下载前及发布文件前复核引用，退出/切换取消相关任务。国内CDN不携带账号Cookie/SID；旧HTTP写法只在已知CDN的同一主机升级HTTPS，不明文回退。

用户已接受非官方接入无法保证零风控风险。自动化只使用合成会话和内存钥匙串替身；匿名可用样本不等于真实VIP权限验收。真实会员需要用户主动在App登录后测试对应版本。

## 0.8.0 默认匿名与可选账号

所有来源默认匿名。`use_connected_accounts`默认为false，已有会话也不会自动附带；仅用户显式启用后，之后添加的网易云/酷我任务可附带对应版本引用。新增四源不读取账号，也不显示不能工作的登录入口。切换方式撤销旧试读缓存。匿名整首、登录整首和仅试读分开显示，未知访问方式不计入任何一种账号类别。

0.8.4在进入账号排队前捕获连接意图；排队期间退出或换号使旧候选失效。排队期限与两秒节流使用单调时间。风险暂停文件无法写入时，进程内仅保留目录、平台、会话版本和原因码，并拒绝该版本的后续请求；界面同步暂停并撤销匹配任务，保留匿名/其他来源和已提交成功。内存兜底不跨进程保存；退出或成功新连接后清理相应旧状态。
