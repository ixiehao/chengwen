# 0.9.0 下载诊断与完整性

失败原因、解决办法及安全技术状态分开保存。用户可重新解析和重试；重试仍失败提示换来源或歌曲版本，记录不含Cookie、SID或签名URL。

| 类型 | 显示与处理 |
| --- | --- |
| source_unavailable / source_response | 返回HTML、无效数据或无可用音频；重新搜索、测试或换源。 |
| network / network_timeout | 网络断开或超时；检查网络后重试。匿名搜索遇连接丢失/超时最多额外重试一次。 |
| rate_limited / account_risk | 平台限流/安全验证，停止本次请求并暂停对应账号自动请求。 |
| account_expired / account_changed | 会话过期或已退出/切换，不使用旧引用、不退回匿名地址。 |
| account_permission | 没有该版本下载权益、错歌、试听或保护格式；拒绝当作完整歌曲保存。 |
| dependency / tool_launch / tool_timeout | 缺少、无法启动或超时的FFmpeg/FFprobe；打开运行环境测试检查兼容工具。 |
| audio_invalid / audio_incomplete | 不可识别、编码/容器错误、时长不符或实际可解码内容不足；拒绝发布。 |
| filesystem | 空间、配额、目录权限或写入问题；更换保存位置或释放空间。 |

预下载仅试读最多128KiB，即使服务器忽略Range也主动停止。通过不等于整首必然成功。API响应按流限制8MB，音频最大512MB；在写入、采样及进度回调之前检查剩余预算，已知全下载长度超限时直接拒绝。

整首下载收到HTTP206时，必须明确覆盖从0到总长减1的整个对象，Content-Length不得矛盾，实际接收字节也须等于总长。部分对象、未知或无效范围不能被当作整首；受限预下载仍允许正常206响应。

下载写到目标目录中的0700私有临时目录，文件0600。检查真实音频流、所选codec/container、头时长和FFmpeg整段实际解码时长；原始格式也必须完整解码，避免VBR/Xing头谎报时长。转换和完整解码启用严格错误终止，坏帧不能因工具默认恢复并返回0而被当作完整音频。发布前检查取消及账号版本，支持排他重命名的同文件系统以原子提交创建最终名称，已有文件/目录/符号链接不覆盖。ExFAT 等不支持卷只在明确不支持排他重命名时改用排他创建和分块复制，完成同步写入后才提交成功；普通失败或取消会按文件归属清理。该兼容路径不是原子写入，强退/断电可能留下未完成音频，不能把它描述成支持卷相同的提交保障。失败/取消清理临时目录。

已保存音频后若歌词获取或写入失败，任务仍是完成并显示歌词警告，不把已有音频误报为失败。平台正常没有歌词不作为故障；提交后的取消不撤销已安全保存的文件。任务和历史只保存公开元数据及本地文件位置。

API会话请求不跟随跨源跳转。音频请求不带账号Cookie/SID；已知国内CDN的旧HTTP写法仅在发出请求前升级同一主机到HTTPS，未知HTTP、凭据URL及公网重定向到回环地址均拒绝，不降级明文。

## 六源匿名失败分类（0.8.0）

- `source_permission`：平台没有为当前匿名请求返回完整音频权限；选择允许匿名访问的其他版本或换源。
- `audio_preview`：平台明确返回试听标志、试听时长或明显较短的媒体；不请求或保存为整首。
- `source_verification` / `rate_limited`：额外验证或频率限制，停止本次请求，不循环重试。
- `source_response`：响应结构或资源身份不一致；不将新结构静默当成零条搜索结果。

六个来源使用同一下载校验管线。搜索、试读、匿名整首及登录整首分别记录；有URL也必须通过状态码、身份、HTTPS来源和完整性校验。只有下载后的明确验证结果才显示整首成功。

## 历史记录恢复与保存

兼容旧数组历史，新写入使用带版本的历史格式；读取有20MB和5000条上限。0.8.2保存时保留所有未完成任务（包括中断任务）与最近500条已结束记录，保持加入顺序；若保留结果仍超过上限则拒绝保存，不覆盖原文件。空或重复任务标识会修复后保留任务；损坏、超限或不支持版本的原文件先备份。备份失败时阻止继续覆盖并提示，避免误把读取失败当成空记录。保存失败会显示提示；清除记录须成功落盘后才修改列表，不删除音乐文件。

0.8.4工具执行超时覆盖自有进程组和继承管道，取消时回收后代；不依赖直接子进程仍在运行。工具返回超过2MB时使用`tool_output`并提示检查工具和输入，区分主动取消。无法确认退出状态或工具留下后台任务时不计成功；主动脱离进程组的外部守护程序不在本次清理范围。预下载缓存仅接受0至不足300秒的年龄，未来时间戳不阻止重试。
