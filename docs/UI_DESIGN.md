# 0.9.0 macOS 原生界面

UI设计师分别负责整体布局和AppKit控件，测试工程师验收交互。系统语义背景、标签、分隔线、选中颜色和强调色跟随浅色/深色外观，使用系统字体；应用操作图标继续使用Tabler Icons。系统控件自身的箭头、焦点环和复选框由macOS绘制。

默认窗口1220×820，最小1080×740。保留红黄绿按钮，内容背景延伸到顶部，不增加独立标题栏背景或固定底部状态栏。原生侧栏195pt，右上角始终为运行环境测试入口。页标题统一27pt，内容水平边距24pt。

搜索标题为「搜索你想找的音乐」。左侧NSSearchField、搜索按钮和最近搜索，清空紧邻历史标签；右侧直接显示六来源：常用宽度一行，窄窗口自动两行三列，来源不放进下拉菜单。Command+F聚焦搜索，Return仅提交一次；原生清除按钮只清空输入。

结果使用真正的NSTableView和NSScrollView，原生列标题、交替行、滚动条、焦点及选择。首列真实三态复选框，空结果禁用；逐行checkbox和原生多选共享稳定歌曲ID。Command+A只响应当前firstResponder，输入文字不会误选歌曲。歌曲与专辑列可调宽，长文字截断后可查看完整tooltip。时长采用等宽数字；短于60秒的结果在歌曲名旁标记「片段」。

蓝色「可试读」只代表受限试读；绿色「整首已验证」必须来自实际完整下载校验，并区分匿名与已登录。来源状态分别展示当前搜索和完整验证统计。试读或操作完成不会产生整首证明。

保存位置和更改入口相邻，格式采用系统NSPopUpButton真实菜单，使用系统选择指示符；数值输入使用NSTextField和NSStepper，提交时规范范围并维护编辑焦点。下载展示按加入顺序倒排，调度仍保持FIFO。

设置使用统一紫色卡片和表单行，页签按实际内容宽度收口。通用、账号与音源、运行环境各自分组，标签、值及辅助说明对齐。账号下载默认关闭，官方WKWebView登录使用系统强调色和标准取消/默认按钮，不改变账号事务。

操作反馈为内容区右上角约320pt系统材质浮层，约3秒自动消失，可手动关闭，不参与布局。重复提示重置时限，旧计时不能关闭新提示；失败原因和解决办法保留在对应任务中。

运行环境弹窗固定标题与底部按钮，正文滚动；始终可查看Homebrew、MacPorts和手动安装说明、复制命令和打开工具目录。安装状态与说明均验收明暗外观，不将工具缺失误报为已就绪。

验证区分真实AppKit控件动作、模型测试、合成窗口排版和安装副本运行。未进行Monterey12.7.6或物理Intel实机测试时明确记录，合成账号不代表真实会员验收。

下载管理复用搜索表格的原生列头、交替行、歌曲图标及选中态。固定48pt行高，列为歌曲/艺术家、来源、格式、状态/进度、说明、操作。长错误单行截断并有完整tooltip；详情浮层包含完整原因和解决办法，任务清除或重试后关闭失效浮层。状态和长文案不再撑大整行。
